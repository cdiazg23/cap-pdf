# CAP PDF

Una herramienta gratuita para Windows que permite ver, organizar y preparar documentos PDF, con un asistente de IA opcional. Un proyecto de Cápsulas de Derecho ([@capsulasdederecho](https://www.tiktok.com/@capsulasdederecho) en TikTok).

## Descargar

**[Descargar la última versión](https://github.com/cdiazg23/cap-pdf/releases/latest)** y ejecutar el archivo `CAP-PDF_…_x64-setup.exe`.

Requiere Windows 10 u 11 de 64 bits.

> **Aviso de Windows al instalar.** El instalador todavía no tiene firma digital, así que Windows puede mostrar «Windows protegió su PC». Pulsa **Más información** y luego **Ejecutar de todas formas**.

## Qué puedes hacer

- **Unir** varios PDF en uno.
- **Dividir o extraer** las páginas que elijas.
- **Organizar**: reordenar, rotar y eliminar páginas.
- **Imágenes a PDF**: JPG, PNG, WebP, BMP y GIF.
- **Numerar páginas** y añadir **marca de agua**.
- **Preguntar con IA**: resumir el documento o hacerle preguntas, usando tu propia clave de API de Anthropic.

Tus archivos originales nunca se modifican: el resultado se guarda siempre como un PDF nuevo. El manual completo está dentro de la aplicación, en «Manual de uso».

## Privacidad

Tus archivos se procesan en tu equipo y no se suben a ningún servidor. Lee la [política de privacidad](PRIVACIDAD.md).
