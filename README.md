# CAP PDF

Una herramienta gratuita para ver, organizar, editar y preparar documentos PDF, con OCR y un asistente de IA opcional. Funciona en el navegador, sin instalar nada. Un proyecto de Cápsulas de Derecho ([@capsulasdederecho](https://www.tiktok.com/@capsulasdederecho) en TikTok).

## Usar ahora, sin instalar

**[Abrir CAP PDF en el navegador](https://cdiazg23.github.io/cap-pdf/)**

Funciona en computador y en celular, sin crear cuenta. Tus archivos no se suben a ningún servidor: todo se procesa en tu propio dispositivo. Desde el menú del navegador puedes instalarla («Instalar aplicación» o «Agregar a pantalla de inicio») para abrirla como cualquier otra app.

## Qué puedes hacer

- **Unir** varios PDF en uno.
- **Dividir o extraer** las páginas que elijas.
- **Organizar**: reordenar, rotar y eliminar páginas.
- **Editar**: añadir texto, resaltar, dibujar o firmar a mano, y cubrir zonas.
- **Seleccionar y copiar** el texto del documento.
- **OCR**: volver seleccionable el texto de escaneados y fotos, en español e inglés.
- **Imágenes a PDF**: JPG, PNG, WebP, BMP y GIF.
- **Numerar páginas** y añadir **marca de agua**.
- **Preguntar con IA**: resumir el documento o hacerle preguntas con tu propia clave de API de Groq o Google Gemini (ambos con plan gratuito), OpenAI o Anthropic.

Tus archivos originales nunca se modifican: el resultado se guarda siempre como un PDF nuevo. El manual completo está dentro de la aplicación, en «Manual de uso».

## Versión de escritorio para Windows (opcional)

También hay un [instalador para Windows](https://github.com/cdiazg23/cap-pdf/releases/latest) de 64 bits. Es una versión anterior a la web y todavía no incluye edición, OCR ni los tres proveedores de IA.

> El instalador no tiene firma digital, así que Windows puede mostrar «Windows protegió su PC». Pulsa **Más información** y luego **Ejecutar de todas formas**.
